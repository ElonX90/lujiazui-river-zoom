# 用 Perspective Illusion 制作循环视频

这套方法适用于街道、站台、商店、走廊和滨水景观。先用窄视角和较远机位把前后景拍得像一张插画，再联动机位与镜头焦距，让遮挡和相对大小发生变化，显露场景纵深。最后把镜头和场景运动接回开头。

## 工具和技能怎么分工

| 工具或技能 | 作用 | 本项目的用法 |
| --- | --- | --- |
| Codex + Perspective Illusion skill | 读取场景模板，设计镜头与循环，编写和调试场景 | 采用长焦压缩、分层视差和循环镜头 |
| ImageGen | 生成底图、透明前景、独立人物或车辆素材 | 制作雨夜天际线、外滩步道和渡轮 |
| Three.js | 搭建空间、安排遮挡，控制相机、反射和粒子 | 把插画放到不同深度，按时间计算每帧 |
| Playwright + Chromium | 运行 Three.js 场景，逐帧截图 | 预览关键帧，再输出完整序列 |
| FFmpeg / ffprobe | 把图像和音轨编码为 MP4，检查规格 | 输出 1080 × 1920、60 fps、10 秒的视频 |

技能源见 [Perspective Illusion 的 SKILL.md](https://github.com/dotslashsimran/simcraft/blob/main/skills/video/perspective-illusion/SKILL.md)。在 Codex 中安装该技能后，直接在任务中点名它。已提供的外滩工程可直接运行，无需再次生成素材。

## 1. 写制作提示词

把地点、画面、运动和交付规格分开写。明确开场和结束的画面，指定镜头在何时改变，以及哪些物体应该随镜头产生视差。需要真实地理或交通逻辑时，把这些要求写成具体空间关系和行为。

```text
使用 Perspective Illusion skill 制作一段 [时长] 秒 [宽高比] 的循环插画视频。
地点与方向：[从哪里看向哪里]。保留 [实际地标、道路或水岸关系]。
空间分层：近景 [物体]，中景 [物体]，远景 [物体]。
风格：以 [色彩、光线、笔触、天气] 为主。参考图用于 [构图、质感或镜头]。
镜头：
- 开场以远机位和窄视角压缩空间，画面像平面插画。
- 逐渐向前推，并联动焦距。让 [近景] 先出画，[主体] 在 [时间点] 清楚入画。
- 用同一轴线退回开场；如需侧转，明确起止时间和方向。
运动：[船只、行人、车流、雨滴] 的方向、节奏和接地要求。
交付：先出开场、中景、最近点和结尾预览；确认构图后导出 [分辨率 / 帧率] 的 MP4。
```

素材提示词单独写，每张图只负责一个空间层。把相机高度、光源方向和调色在各素材提示词中写一致，透明层要明确要求真实 alpha 和完整轮廓。例如外滩案例可以拆成：

- **远景底图**　竖屏雨夜插画，从浦西外滩隔黄浦江看浦东。东方明珠与陆家嘴三件套轮廓清晰，远岸位于约画面 58% 高度，下部留出带倒影的江面。
- **近岸前景**　同一雨夜光线，外滩栏杆、红伞和湿石板路，人物完整。栏杆上方及缝隙透明，保留路面的反光。
- **运动物体**　同一笔触，浦江客渡轮侧视，朝右，船身、灯窗和尾迹完整，背景透明。

遇到具体问题，给出可检查的改稿提示。例如「同向车辆走道路右侧，轮辐随实际位移滚动。相机从斜后方取景，抽查连续帧能看到轮辐变化」。仅移动车身或行人的整张贴图，会产生平移感。近景车辆宜用可转动的轮组，行人宜用带关节的模型或行走序列。

## 2. 选择场景做法

- **完整 3D 场景**适用于侧转、街头推进、人物和车辆近景。用 Three.js 构建建筑和运动部件，插画贴图负责表面细节。可从技能的雨夜街道、商店等模板选起。
- **分层插画场景**适用于以正面推进为主的作品。将近景、主体和远景放在不同深度，地面或水面跨越这些层。镜头移动时会产生视差，同时保留原画笔触。

## 3. 设计镜头和循环

1. **确定参照面。** 选一面招牌、一座建筑或一个街口作为视觉锚点。长焦开场先把前后层对齐，保留可辨认的轮廓。
2. **联动距离和视角。** 若参照面在镜头前的距离为 `d`、希望该面可见的高度为 `h`，垂直视角为 `2 × atan(h / (2 × d))`。推近时保持 `h` 可突出空间变化，减小 `h` 则会把主体进一步放大。
3. **按需要旋转或移轴。** 侧转能展示物体侧面。外滩案例固定相机方向，用投影偏移把观众视线引向浦东楼群。推近前确认素材支持镜头会看到的区域。
4. **对齐首尾。** 机位、视角、取景偏移和可见物体状态都要闭合。雨滴等重复运动用整数周期；驶出画面的船可从画幅外接续。检查结尾接开场的实际播放效果。

## 4. 实战案例《隔江看陆家嘴》

开场从岸边红伞望向黄浦江和浦东天际线。推进时红伞和栏杆先出画，渡轮与对岸楼群产生不同幅度的视差。第 5.6 秒抵达三件套近景，再沿轴线退出。三维场景和镜头曲线在 `scene.html`，`render.mjs` 用浏览器逐帧渲染，`rain.wav` 是配套音轨。

准备 Node.js、浏览器和 PATH 上的 FFmpeg。从仓库根目录运行：

```sh
npm install
npx playwright install chromium
node render.mjs --proof
node render.mjs
ffmpeg -framerate 60 -i frames/%04d.jpg -i rain.wav -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac -b:a 224k -movflags +faststart -t 10 bund-river-zoom.mp4
ffprobe -v error -show_entries stream=width,height,duration,nb_frames,avg_frame_rate bund-river-zoom.mp4
```

若使用本机 Chrome，可把 `CHROME_PATH` 设为浏览器可执行文件路径。预览会输出若干 `proof*.jpg`。先看推近时四座地标是否被意外拉伸、画面边缘是否露底，再看渡轮和倒影是否同步。正式导出后核对视频为 10 秒、600 帧，开启循环听雨声和船笛是否自然衔接。
