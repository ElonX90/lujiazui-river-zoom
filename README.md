# 隔江看陆家嘴

用 Three.js 搭建分层雨夜插画，用 Playwright 逐帧渲染，再用 FFmpeg 合成 10 秒竖屏循环。镜头沿前后轴线穿过画面纵深，推向浦东天际线，再沿原路返回。

## 1. 准备素材

使用一张 9:16 的外滩雨夜底图，画出天空、浦东楼群和黄浦江。另做两张透明 PNG，分别是带红伞和栏杆的外滩前景，以及侧面的渡轮。把楼群从底图单独抠出，再补一张干净的云层底图。

示例中的 `city.png` 提供江面的纹理，`silhouette.png` 是带透明通道的楼群，`clouds.jpg` 是补过的天空，`boat.png` 和 `front.png` 分别对应渡轮和近岸。

## 2. 用 Three.js 搭分层场景

把天空放在最后，楼群排在天空前方。用贴有原画江面纹理的斜四边形连接远岸和近岸，把渡轮放在江面中段，再把红伞和栏杆放在最前面。这样推近时，前景比楼群更早离开画面。

渡轮沿江横向移动，并用轻微起伏表现水面波动。倒影翻转、压扁后以低透明度绘制，江面着色器用正弦函数扰动采样坐标。

## 3. 设计正面变焦

相机的横向位置和朝向固定。镜头距场景从 64 缩到 6.8 个场景单位，焦平面可见高度从 8.08 缩到 4.38。联动这两项，既能看到前中后景的相对运动，也能把三件套放大成近景。

用 `2 * atan(可见高度 / (2 * 焦平面距离))` 求垂直视角，并通过投影矩阵的镜头偏移把取景中心引向三件套。第 5.6 秒到达最近点，随后以余弦缓动退回。雨滴和涟漪使用整数周期，渡轮从画幅外接续进场。

## 4. 渲染与编码

需要 Node.js、Chrome 或 Playwright Chromium，以及在 PATH 上可用的 FFmpeg。

```sh
npm install
npx playwright install chromium
node render.mjs --proof
node render.mjs
ffmpeg -framerate 60 -i frames/%04d.jpg -i rain.wav -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac -b:a 224k -movflags +faststart -t 10 bund-river-zoom.mp4
```

先检查预览的开场、中景、最近点和循环接点，再导出全片。1080 × 1920、60 帧/秒的 10 秒视频应有 600 帧。成片可以用 `ffprobe` 验证，并在播放器开启循环检查声音与画面的首尾衔接。
